Con l'aggiornamento uscito l'8 settembre per Windows 11 (25H2 e 24H2), Microsoft ha ascoltato una richiesta di anni: **poter personalizzare di più Start e barra delle applicazioni**. Ecco cosa si può fare.

## Prima di iniziare

L'aggiornamento distribuisce le novità **a poco a poco**: potresti avere il sistema aggiornato e non vedere ancora tutte le opzioni. È normale. Per prima cosa vai su <span class="percorso">Impostazioni → Windows Update</span> e installa tutto quello che c'è.

## Il menu Start

Apri <span class="percorso">Impostazioni → Personalizzazione → Start</span>. Le novità principali:

- **Dimensione**: puoi scegliere tra un menu Start piccolo, grande o automatico.
- La sezione "Consigliati" ora si chiama **Recenti**.
- Puoi **nascondere nome e foto profilo**.
- Le sezioni **Aggiunte, Recenti e Tutte le app** si attivano o si disattivano separatamente.

Se non ti serve lo spazio dei suggerimenti, spegnili e lascia solo le app che usi davvero: Start diventa più pulito e veloce da usare.

## La barra delle applicazioni

Apri <span class="percorso">Impostazioni → Personalizzazione → Barra delle applicazioni</span>. Con l'aggiornamento arrivano:

- la possibilità di **cambiare posizione** alla barra;
- una **barra più piccola**, utile sui portatili con schermo piccolo.

Sono le funzioni che Microsoft attiva più lentamente: se non le trovi, aspetta o installa l'[aggiornamento di anteprima](../windows-11-aggiornamento-anteprima-copilot-tasto-bluetooth/).

## Una nota sui "trucchi"

In rete circolano guide che fanno attivare queste funzioni in anticipo con comandi da riga di comando (ViveTool). Funzionano a volte, ma sono strumenti non ufficiali: **se non sei pratico, evitali**, perché possono rendere il sistema instabile.

> Personalizzare Windows è un modo semplice per lavorare meglio senza spendere niente. Cambia una cosa alla volta, così puoi sempre tornare indietro.

## Se il PC è lento

Un Start più leggero aiuta, ma non fa miracoli. Se il problema è l'avvio, leggi [PC lento all'avvio](../pc-lento-avvio-windows-11/). E per fare screenshot delle tue nuove impostazioni, usa [la guida agli screenshot](../fare-screenshot-su-ogni-dispositivo/).
